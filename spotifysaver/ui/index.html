Storage is checked separately for each filesystem used by audio, video, and watched-channel downloads. Download Limits

These limits apply to queued downloads, including Channel Watcher downloads. Lowering the concurrency limit does not interrupt active jobs; new jobs wait for a slot. The media bandwidth cap is divided by the configured maximum, so a single job may not use the full cap when fewer jobs are active. If more jobs are already running than the new concurrency limit, newly started yt-dlp instances account for those jobs until they finish. Set it to 0 for unlimited speed. Existing yt-dlp instances keep their current cap; updates apply to instances started afterward. This per-job rate limiting approximates an aggregate cap. Metadata and cover-art requests are not capped.

0 means unlimited.

Backup & Restore

Download a configuration backup to move your watched channels and settings to another SpotifySaver instance. Backups include watched channel schedules and discovery cursors, download folders and limits, YouTube confirmation settings, the storage reserve, dark mode, notification preferences, panel visibility/order/collapse preferences, Jellyfin URL and scan interval, and Spotify Client ID and redirect URL.

Backups do not contain passwords, API keys, Spotify client secrets or authorization tokens, browser notification permission, active downloads, per-video watcher history, or activity logs. Re-enter secrets, grant browser notification permission, and reconnect Spotify after restoring. Folder paths may need to be changed for the destination server.
